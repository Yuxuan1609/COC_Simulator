=== SYSTEM ===
你是一个 TRPG 模组解析助手，专门生成 Boss 遭遇实体。
你的任务是：基于 Step 1 的 Boss 识别结果和已知 L2 entity，生成结构化的 Boss Encounter 实体。

术语：interaction、auto_trigger、event、boss_encounter 统称为 entity（实体）。

重要原则：
- boss_ref 必须从 Boss 库中选择，不允许自创
- requirements 使用 (entity ID + AND/OR/()) || 软性条件 格式，硬性部分引用已知 entity ID
- engage_type 判定: 进入场景自动触发→"at", 玩家主动操作→"interaction", 全局条件满足→"event"
- description 是进入战斗时的情境描述，基于精修模组内容扩写
- entity 的 result/side_effects 不涉及战斗/对抗的详细过程（战斗由 game loop 运行时统一管理），但可以声明怪物出现和情境
- 仅输出 JSON，不要任何解释性文字

## 精修模组（参考上下文）
"""
1937年深秋，河南与山西交界处的太行山腹地，灰白色的浓雾如同凝固的尸布，将一座名为星陨村的古老村落与世隔绝。三个月前，矿工们在村北矿井深处炸穿了一道刻满咒文的黑石壁，释放出被远古文明封印的异界存在——“深渊之口”。它并非血肉之躯的怪物，而是一种以记忆为食、以遗忘为疆域的概念性恐怖。它通过三件被拆分的法器与现世互动：铜镜吞噬人类的记忆与身份；玉刀以血肉为代价换取保护；雕像则是深渊的嘴，是封印的基石。法器一旦重聚，深渊之口将彻底降临，吞没一切存在过的痕迹。

村庄已被封锁。大多数村民的记忆被抽走，沦为眼神空洞的行尸走肉，在雾气中漫无目的地游荡。墙壁上留下了炭笔写就的绝望警告，民居内横陈着器官被精准摘除的尸体——那是深渊通过梦境逼迫人们模仿古代封印仪式的结果。矿井每天黄昏涌出更浓的雾，矿主马德胜已被铜镜反噬，变异为深渊的奴仆，带领着被吞噬记忆的矿工大军，围堵任何试图接近真相的人。

调查员被一封求援信引入这片绝地。古董商孙伯安在失联前发出紧急电报，请求鉴定所谓“唐代古墓”出土的文物。同行的还有考古学者、医生、护卫，抑或调查员自己就是前来寻人的亲属、调查异常事件的秘密组织成员。他们将在弥漫的恐怖中逐步拼凑真相：勘察废弃民居，翻阅孙伯安的笔记，聆听濒死僧人明觉的遗言，在村中碉楼破译古代封印卷轴。时间如刀刃般锋利——每度过一个夜晚，雾气便浓一分，记忆便薄一分，调查员自身也可能开始遗忘同行者的名字、此行的目的，甚至自己的身份。

秘密的揭露将引导他们深入矿井，抵达黑石层深处的地下祭坛。在那里，三件法器的真正用途、古代封印的三种方式将呈现于前。调查员必须在最终抉择中决定：是以鲜血为契、以咒术为笼、还是以生命为烛，来封堵那道即将彻底撕裂现实的裂缝。抑或，在深渊的诱惑面前，被吞噬入永恒的虚无。

整个历程预计持续数日，每一个夜晚都是生与死的考验，每一段记忆的丧失都可能改变结局的走向。星陨村的命运，以及更广阔世界中被遗忘的安宁，悬于一线。

### 空壳村民与矿工

这些曾经是普通百姓和矿工的人类，如今只剩下一具具被掏空了记忆的皮囊。男女老少皆有，身穿日常衣物或矿工作服，但衣衫破损，沾满泥污与黑色的霉菌斑。他们的眼睛呈现出统一的灰白色，仿佛被一层翳膜覆盖，没有瞳孔，也没有任何可以称为“视线”的焦点。动作起初迟钝僵硬，但在群体行动或在深渊意志的驱动下会突然加速，爆发出不受肉体限制的力量。一些矿工手里还拖着镐头或铁锹，他们不流血，伤口处只有灰白色的菌丝在蠕动。

这些空壳遍布整个星陨村及其周边，在雾中尤其活跃。围攻碉楼时，马德胜能召集数十名空壳矿工连续撞击大门。他们可以进行徒手攻击或挥砸工具，也能进行群体擒抱，压制目标的行动。当多个空壳同时靠近时，他们身上残留的深渊能量会形成一种记忆干扰场，令目标感到自己的记忆开始飘忽不定。死亡的矿工尸体在倒下后不久会爆发出一小片孢子云，吸入会导致中毒。

空壳对火焰有本能的畏惧，火焰能有效阻止他们前进。手持玉刀者散发的气息能令他们短暂迟疑，且免疫其记忆干扰。一旦铜镜被逆咒反噬释放记忆，所有空壳会瞬间恢复神智，不再攻击。调查员应尽量避免与大量空壳正面对抗，可以利用狭窄地形防守，或制造噪声引开他们。他们的移动速度不算快，但会持续追踪。

### 马德胜（变异矿主）

他曾经是一个普通的矿主，中年富态，精明算计。如今身高拔至近两米，皮肤呈不健康的铅灰色，无数丝线粗的黑色脉管从脖子攀爬至面部，在皮下像寄生虫一样蠕动。他的双目仍有瞳孔，但虹膜是液态的水银色，不断流动，仿佛两面微型的铜镜。左手已完全变异为生殖怪物——约十根不断蠕动的触手状手指取代了原来的五指，每根指端都有一只微小但能转动的眼睛。右手仍保持人形，紧紧握着那面暗金色的铜镜。他开口说话时，嘴角会裂开到不正常的宽度，露出不再属于人类的齿列。他穿着破烂不堪的绸缎长衫，上面沾满了黑色粘液和干涸的血迹。

马德胜通常单独出现，但会带领一群空壳村民。他会在碉楼外喊话要求交出玉刀，之后在矿井中追击调查员，进行最终决战。他的主要武器是铜镜——举起铜镜照射可以吞噬目标的记忆，被照射者会随机遗忘一段记忆，导致技能临时下降、忘记同伴的名字甚至忘记自己为何在此。他的触手可以进行多次中距离攻击，带有麻痹毒素。他的声音带有深渊的低语，能让听到的人逐渐丧失理智。他对常规武器有极高的抗性，子弹和刀刃只能造成一半的伤害，只有玉刀、刻有咒文的武器或火焰能造成全额伤害。

玉刀是克制他的关键。用玉刀攻击可以暂时封印他的触手能力，若将玉刀刺入他体内，会引发他体内深渊能量的紊乱，造成毁灭性的伤害。若在咒阵中对铜镜发动逆咒，马德胜会因记忆倒灌而陷入混乱。他仍残存部分人类的执念，用他曾经的身份（父亲、丈夫）来动摇他，可能让他产生一瞬间的犹豫。在正午阳光下，铜镜的力量大幅减弱，他失去记忆吞噬能力。如果铜镜被夺走或破坏，他的变异抗性会大幅下降。

他会在调查员取得玉刀后感应到并开始主动追踪，在碉楼夜战时必然出现，若调查员潜入矿井他会尾随而至并伺机偷袭。这是难度极高的战斗，最佳的应对方式是将他引诱到矿井黑石层的咒阵中，发动封印结界或逆咒将其削弱，再用玉刀给予致命一击。

### 深渊衍生物（触须集群）

从空腔裂缝中探出的不定型黑色触手，没有明显的头部或躯干，只是无数条庞大肢体的聚合。每条触手粗如人腿，长度在五到八米之间，表面布满吸盘和倒刺，在裂缝的紫光映照下闪烁着湿润的光泽。它们静止时舞动如深海海草，攻击时则迅猛如鞭。数量视裂缝张开程度而定，通常为一到三条，若封印失败或法器被暴力破坏，裂缝会喷涌出更多。

触手会缠绕目标，每回合施加勒压伤害并尝试将被捕获者拖向裂缝。被拖入裂缝的角色将从模组中永久消失，其存在本身被抹消。触手也可以进行远距离鞭打抽击，伤害较高。被触手接触的人会直接听到深渊的“声音”，每回合不断损失理智。部分触手尖端的吸盘能喷出黑色孢子，产生弱效的记忆干扰效果。

触手并非无敌，每条的生命值约等于一个健壮成年人的一点五倍，可以被集火斩断，但砍断后伤口会喷溅具有腐蚀性的剧痛液体。触手在被普通武器砍断后会在数个回合内再生，只有玉刀能阻止这一过程。将铜镜和玉刀放入祭坛凹槽能暂时让裂缝合拢，触手也会随之退缩。法术封印展开的蓝光可以灼伤它们，将它们逼回裂缝。触手极度不耐火焰，但矿井深处很难生起足够大的火势。
