当前技术栈

优点

  • 零前端依赖，纯 vanilla JS
  • Python 生态统一，PyInstaller 可打包
  • 设计风格统一（COC 1920s 克苏鲁美学）
  • 架构简单，易于理解

问题

  • 两个 server 端口冲突（都默认 8080）
  • http.server 单线程阻塞（LLM 调用期间卡死）
  • game.html CSS/JS 全部内联，难以维护
  • 硬编码 localhost:8080，不可配置
  • 离线环境 Google Fonts 加载失败
  • 无 WebSocket，无实时反馈

项目约束

  • Python 为主后端（LLM 驱动游戏引擎）
  • PyInstaller 打包桌面分发
  • 单用户本地工具
  • 需要离线可用
