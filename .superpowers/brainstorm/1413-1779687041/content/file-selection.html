文件/模组选择系统

前端文件浏览器 + 后端动态加载，覆盖 4 类资源

统一文件选择组件

组件行为:
• GET /api/files?dir=data/modules → 返回目录列表 JSON
• 前端渲染为可选列表（HTMX hx-get 刷新）
• 用户选择 → 路径传给对应 API
• 支持单选（选模组）/ 多选（选多个库文件）
• 当前选择高亮 + breadcrumb 路径显示

安全约束（本地工具，但仍然重要）:
• 限制浏览范围到项目根目录
• 只显示 .json / .docx / .txt / .pdf 等白名单扩展名
• 路径参数校验，拒绝 ../ 逃逸

四类资源的文件选择

1. 模组生成

源文档: data/ 下选 .docx / .txt
输出目录: data/modules/ 下新建或选择已有
已有模块: 选择已有 L2 JSON 作为参考/补充管线输入

2. 游戏模组

L1/L2/L3 文件: data/modules/{name}/l*_test.json
或自由指定三个路径（支持不同目录）
起始场景: 从 L2 JSON 解析后下拉选择

3. 调查员

角色卡: investigator/*.json
预设角色卡选择 + 新建车卡入口

4. 标准库

武器库: data/library/core/weapons.json
+ data/library/extensions/ 扩展
敌人库: data/library/core/enemies.json
Boss 库: data/library/core/bosses.json
每项支持多选（核心 + 多个扩展）

API 设计

# 文件浏览
GET /api/files?dir=data/modules → {files: [...], dirs: [...], parent: "..."}

# 模组生成
POST /api/pipeline/start → {source_docx, module_name, output_dir, steps}
WS /api/pipeline/progress → 实时推送 18 步骤状态

# 游戏初始化
POST /api/game/init → {l1_path, l2_path, l3_path, start_node, char_path}
POST /api/game/library → {weapon_paths[], enemy_paths[], boss_paths[]}

# 配置持久化
POST /api/config/save → 将当前选择保存到 config.json
GET /api/config/load → 加载上次配置（启动时自动恢复）
