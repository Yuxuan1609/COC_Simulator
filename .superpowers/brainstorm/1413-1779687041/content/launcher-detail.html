启动页面（Launcher）详细设计

三个功能区：模组创建引导 + 参数配置 + 导航入口

功能区 A：模组创建引导
Step 1: 上传源文档（.docx / .txt）
Step 2: 填写模组名称 + 选择输出目录
Step 3: 选择管线步骤（全量 / 从某步续跑）
Step 4: 点击"开始生成"
Step 5: WebSocket 实时进度（18 步骤）
每步完成 → 前端更新进度条 + 中间 JSON 预览
Step 6: 下载 L1/L2/L3 JSON 文件

对应现有 run_pipeline.py CLI → 变为 Web GUI
功能区 B：参数配置
API 配置:
• API Key 输入（加密存储到 .env）
• 模型选择（deepseek-v4-pro / flash / 自定义）
• Thinking 开关 + Reasoning Effort 档位

管线参数:
• LLM 超时阈值 (LLM_TIMEOUT_MS)
• 慢调用阈值 (LLM_SLOW_THRESHOLD_MS)
• 降级策略 (DEGRADE_POLICY)
• Combat LLM 增强开关

游戏设置:
• 默认模组选择
• 日志级别 / 输出路径
• 调试模式开关
