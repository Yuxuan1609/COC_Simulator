操作指南系统

每个页面嵌入上下文相关的用户指引

呈现方式

侧边帮助面板

每页右侧固定可折叠的帮助面板。首次访问默认展开，之后记住折叠状态 (localStorage)。内容随当前步骤/上下文动态切换。

内联提示

表单字段下方灰色小字说明。关键操作旁 "?" 图标 hover 显示 tooltip。对应角色卡现有的 llm-hint 风格。

快速入门向导

Launcher 页面提供 3 步快速入门浮层：① 生成/选择模组 → ② 创建/选择调查员 → ③ 开始游戏。完成后不再显示。

各页面指南内容

Launcher — 帮助面板
模组生成: 什么是 L1/L2/L3？→ 三层信息架构简介
源文档格式要求 → 参考模组创作指南
管线步骤说明 → 18 步各做什么，哪些可选

参数配置: 模型选择建议 → 复杂判定用 pro，简单描述用 flash
降级策略含义 → 何时自动降级到 flash / 确定性逻辑
Character — 帮助面板（随步骤切换）
Step 1: COC 7th 属性说明（STR/CON/DEX/... 各代表什么）
掷骰公式解释（3D6*5 的含义）
Step 2: 职业对应的典型技能
技能点分配策略建议
Step 3: 导出 JSON 的用途（可被 game loop 加载）
Game — 帮助面板
游戏命令: /help 命令列表 + 示例
玩法提示: 如何描述行动 → LLM 解析效果更好
技能检定机制简介（D100 ≤ 技能值 = 成功）
快捷键: Enter 发送，↑ 历史输入
Editor — 帮助面板
JSON 结构说明: L1 字段含义、L2 entity 类型、L3 设计参数
@markup 语法: 7 种副效果标记的格式和参数
校验规则: 自动检查依赖图完整性、entity ID 冲突等
