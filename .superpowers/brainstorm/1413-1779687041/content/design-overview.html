前端重构 — 总体设计

技术栈

后端框架FastAPI (async, WebSocket, Jinja2)
前端交互HTMX (声明式 AJAX, DOM 交换)
样式Tailwind CSS (CDN dev → 本地化 prod)
模板Jinja2 (layout/base 继承, 片段渲染)
实时推送WebSocket (处理步骤进度)
服务器单一 server.py，替代当前 2 个文件
打包PyInstaller (--add-data 模板+静态文件)

页面架构

/ (Launcher 启动页)

项目入口。包含：模组生成引导（上传 docx → 管线进度）、参数配置（API Key、模型选择、管线开关）、三个子页面导航按钮。

/character (车卡创建)

3 步向导：① 基本信息 + 属性掷骰 → ② 职业选择 + 技能分配 → ③ 预览 + 导出 JSON。LLM 辅助描述生成。HTMX 无刷新翻页。

/game (游戏循环)

左右分栏 + 素材图片区。WS 推送处理步骤。侧栏：角色 HP/SAN/状态、场景信息、NPC 列表。主区：叙事消息流 + 输入框。图片区：场景/怪物插图。

/editor (JSON 编辑器)

轻量查看/微调。树形展开 + 关键字段表单编辑。不追求完整 JSON IDE。

数据流

游戏回合:
用户输入 → hx-post /api/game/turn
→ WS 推送: "parse" → "judge" → "enrich" → "narrate"
→ 前端逐步点亮步骤指示器
→ 完成后 HTMX 局部刷新叙事区 + 侧栏状态 + 图片区

车卡创建:
hx-get /character/step/2 → 服务端渲染步骤 HTML 片段
hx-post /character/roll → 返回新属性卡片 HTML
hx-post /character/generate-desc → 返回 LLM 描述文本
hx-post /character/export → 返回 JSON 下载

模组生成:
上传 docx → POST /api/pipeline/start → WS 推送 18 步进度
→ 每步完成前端更新进度条 + 中间产物展示
