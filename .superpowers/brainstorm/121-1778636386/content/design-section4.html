Section 4/4 · Game Loop 适配 + 动态生成触发流

利用现有 improvise_prompt 路径，注入库能力，添加偏离检测

适配后的 Game Loop 流程
Phase 1 · LLM解析动作 (不改)
↓
Phase 2 · LLM判定事件 (不改，并行于Phase1)
↓
Phase 3 · 执行动作 + 消费side_effects (扩展：新增SpawnEnemy/GrantItem)
↓
Phase 3.5 ★ NEW · 偏离检测 + 即兴注入
if all_other and !triggered_events: ← 现有条件：玩家行为无匹配
  deviation_score = L3.evaluate_deviation(context)
  if deviation_score > threshold or runtime_injection_enabled:
    library.injector.runtime() → spawn/grant
    call build_improvise_prompt() ← 现有，增强L3/L1感知
  else:
    现有 improvise 路径（不注入）
↓
Phase 4 · 执行事件 + 引擎二次确认 (不改)
↓
Phase 5 ★ 增强 · 叙事生成
build_narrative_prompt() 现在接收：
  + L1.atmosphere + L1.perceptible ← 结构化感知信息
  + L3.tone_constraints ← 基调约束
  + L3.scene_intents[scene].emotion ← 设计情绪
输出 → 拆解为 L1 结构化更新 + 沉浸式叙事文本
动态生成 · 三种路径总览
路径A · 声明式（JSON锚点）

L2 JSON 中声明 encounters/items → 引擎自动实例化。模组初始化时填充。

触发：进入场景 / 完成前置交互。无LLM参与。

路径B · LLM自主（偏离检测）

玩家行为偏离L3预期路径 → LLM判断需要注入内容 → 查询L3约束 + 库 → 动态生成。

触发：improvise_prompt路径 + deviation_score > threshold。可手动开关。

路径C · 手动命令（测试用）

KP通过命令直接触发。

/spawn enemy Clicker · /spawn weapon "手电筒" · /spawn random · /inject toggle
