注入模块 · 双模式
离线 · 模组构建时

LLM扫描L3 + L2 → 识别需要武器/敌人的场景 → 从库中匹配 → 写入L2 JSON的 encounters/items 字段

例：2号车厢.danger_level=extreme + key_threat=Clicker → inject enemy:Clicker

可开关
在线 · 即兴生成时

LLM判断玩家偏离预期路径 → 查阅L3规则 → 从库中选择 → 动态注入到当前场景

例：玩家在L3标记为safe的车厢反复搜索 → LLM判断需增加紧张感 → spawn enemy:Deep One Spawn

可开关 · 受L3护栏约束
