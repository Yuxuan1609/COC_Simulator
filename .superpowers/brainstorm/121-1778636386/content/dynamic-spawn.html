运行时动态生成机制

确认了双模式注入。现在需要设计：游戏中如何刷怪/发物资？触发者是谁？

三种触发路径
路径A · 玩家行为触发

玩家进入场景 / 执行动作 → Interaction.side_effects 中包含 spawn 类型 → 引擎从库中实例化

例：进入2号车厢 → JSON声明 side_effect: spawn_enemy("Clicker") → 自动生成遭遇
路径B · LLM主动生成

叙事阶段LLM判断"当前情境需要敌人/物品" → 查阅L3设计意图 → 从库中选择 → 生成

例：玩家反复调查某区域 → LLM认为应该给线索 → 建议生成"掉落的手电筒"
路径C · 手动命令

KP或玩家通过命令手动触发 → /spawn 系列命令 → 从库中选择或随机生成

例：/spawn enemy Clicker / /giveitem 手电筒 / /randomencounter

哪些路径应该纳入你的系统？

可以多选——它们并不互斥

A

声明式触发

JSON中声明spawn锚点，引擎自动实例化。确定性，可审计。

B

LLM自主触发

叙事阶段LLM判断是否需要生成内容。高自由度，受L3约束。

C

/spawn命令系列

交互式命令手动刷怪/发物资。用于测试、调试、或人工KP介入。
